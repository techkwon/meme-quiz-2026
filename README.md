# 밈력고사 2026: 너의 밈 IQ는?

![미리보기](og.png)

요즘 중고등학생 밈의 뜻을 맞히고, **AI가 내놓은 답을 그대로 믿어도 되는지** 함께 따져 보는 12문제 웹 퀴즈입니다. 테크권(TechKwon) AI 강의 수업 자료로 만들었습니다.

**바로 풀기:** https://techkwon.github.io/meme-quiz-2026/

## 구성
- 밈 뜻 문제, AI 답 검증, 추천 알고리즘, AI 탐지기 점수, 사용 판단 문제
- 정답 시 컨페티, 오답 시 흔들림, 문제마다 한 줄 해설
- 결과 화면: 점수별 칭호, 헷갈린 문제와 이유를 한 줄로 적는 칸

## 개인정보·안전
- 파일만으로 동작하는 정적 사이트입니다. 서버, 로그인, 분석 추적이 없습니다.
- 이름·점수·입력 내용을 저장하거나 밖으로 보내지 않습니다.
- [가상 예시]로 표시한 AI 답은 실제 서비스 출력이 아닙니다.
- 기기에서 '동작 줄이기'를 켜면 애니메이션이 줄어듭니다. 깜빡이는 효과는 없습니다.

## 수업에서 쓰는 법
1. 퀴즈를 풉니다(약 10분).
2. 결과 화면에서 헷갈린 문제와 이유를 한 줄로 적습니다.
3. "AI 답을 어떻게 확인했는가"를 짝과 설명합니다.

## 출처와 한계
밈 뜻은 문화일보(2026.10.8), 서울경제, HSAD, issueitnow.com을 참고했습니다(확인일 2026-10-23). 밈 뜻은 지역과 시기에 따라 달라지고 빠르게 바뀝니다. 일부 문항은 [확인 필요]로 표시했습니다.

AI 도움을 받아 제작했고, 내용 검토와 수업 판단은 강사가 합니다.
